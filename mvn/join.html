Getting in, step by step

  1. Get the app

    Music Video Night is free to download from the App Store and always free to join a Night with. iPhone, iOS 17 or later.

  2. Be in the same room as the host

    Nights run phone-to-phone over WiFi and Bluetooth — there's no server. Same room, Bluetooth on, and say yes when iOS asks to find devices on your local network.

  3. Tap Join with a Code

    It's right there on the app's home screen. Not the Host button — that one's for whoever is running the Night.

  4. Type the 5 letters, pick a name

    Choose a display name and an emoji avatar and you're in the lobby. Then it's one music video each, on tonight's theme.

Code not working? Codes only last as long as the Night is open, and you have to be on the same WiFi as the host with Bluetooth on. If iOS never asked for Local Network permission, turn it on in Settings → Music Video Night → Local Network. More on the support page.
